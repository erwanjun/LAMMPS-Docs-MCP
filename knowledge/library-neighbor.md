# Neighbor list access

The following functions enable access to neighbor lists generated by
LAMMPS or querying of their properties:

- :cpp`lammps_find_compute_neighlist`
- :cpp`lammps_find_fix_neighlist`
- :cpp`lammps_find_pair_neighlist`
- :cpp`lammps_neighlist_num_elements`
- :cpp`lammps_neighlist_element_neighbors`
