# KSpace styles

All LAMMPS [kspace_style](kspace_style) solvers.  Some styles have
accelerated versions.  This is indicated by additional letters in
parenthesis: g = GPU, i = INTEL, k = KOKKOS, o = OPENMP, t =
OPT.
