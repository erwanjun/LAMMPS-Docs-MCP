## Methods

- **keyword** — Pure keyword: fraction of query terms present, x1.5 for an exact command match
- **tfidf** — Pure TF-IDF cosine similarity over the sparse term vectors
- **hybrid-60-40** — Shipping default: 0.6 x TF-IDF + 0.4 x keyword

- **alpha-0.00** — 0.00 x TF-IDF + 1.00 x keyword
- **alpha-0.10** — 0.10 x TF-IDF + 0.90 x keyword
- **alpha-0.20** — 0.20 x TF-IDF + 0.80 x keyword

- **alpha-0.70** — 0.70 x TF-IDF + 0.30 x keyword

- **alpha-0.90** — 0.90 x TF-IDF + 0.10 x keyword
- **alpha-1.00** — 1.00 x TF-IDF + 0.00 x keyword
- **qdrant-sparse** — Qdrant sparse-vector ANN over the same TF-IDF vectors (cosine via dot product)
- **qdrant-rerank** — Qdrant ANN recall (top 200) then the 60/40 hybrid blend applied locally
